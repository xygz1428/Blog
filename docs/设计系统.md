### 对比度实测（WCAG）

用脚本按 WCAG 相对亮度公式计算，非估算：

| 组合 | 对比度 | 等级 |
|---|---|---|
| 浅色 正文 / 纸底 | **15.20:1** | AAA |
| 浅色 次级 / 纸底 | 9.20:1 | AAA |
| 浅色 弱化 / 纸底 | 5.24:1 | AA |
| 浅色 链接 / 纸底 | **5.36:1** | AA |
| 浅色 链接 / 卡片 | 5.93:1 | AA |
| 浅色 强调 / 纸底 | 3.00:1 | 仅大字 |
| 深色 正文 / 底 | 12.35:1 | AAA |
| 深色 链接 / 底 | 8.09:1 | AAA |
| 深色 弱化 / 底 | 4.03:1 | 仅大字 |

**两条结论：**

1. `--accent`（`#e2672b`）在纸底上只有 **3.00:1**，所以它**只用于装饰**（下划线、边线、进度条），不能当正文颜色用。正文链接因此用深一档的 `--link`（5.36:1）。
2. **深色的 `--fg-faint` 只有 4.03:1**，低于正文 AA 门槛。这是已知不足，用于日期这类辅助信息可以接受，但不要用它排正文。

## 二、字体

| 变量 | 字体栈 | 用途 |
|---|---|---|
| `--serif` | `Noto Serif SC` → `Source Han Serif SC` → `Songti SC` → `Georgia` → `serif` | 正文、标题 |
| `--sans` | `Noto Sans SC` → `Source Han Sans SC` → `PingFang SC` → `Microsoft YaHei` → `system-ui` | 导航、元信息、按钮、图注 |
| `--mono` | `JetBrains Mono` → `Cascadia Code` → `Consolas` → `Courier New` | 代码、日期数字 |

**不引入网络字体**：中文网络字体动辄数 MB，与「首屏快」冲突。全部走系统字体降级链。

## 四、组件样式速查

| 组件 | 关键规则 |
|---|---|
| 文章列表项 | 下边框 1px，最后一项无边框 |
| 标签 `.tag` | 圆角 999px，1px 边框，底色 `--bg-card` |
| 分类卡 `.cat-card` | 1px 边框 + `--bg-card` 底，悬停加深边框 |
| 代码块 | 位置 `relative`（为复制按钮定位），Shiki 双主题 |
| 图注 `figcaption` | 居中、0.82rem、`--fg-faint` |
| 目录 `.post-toc` | 宽屏粘性侧栏，窄屏顶部折叠块 |
| 进度条 | 固定顶部 2px，`--accent` |
| 回顶按钮 | 右下固定 2.4rem 圆钮，滚动 600px 后出现 |
| 灯箱 | 全屏遮罩 `rgba(20,18,16,.86)`，点击/Esc 关闭 |

## 五、主题切换机制

- `<html data-theme="light|dark">`
- 首屏内联脚本读 `localStorage['blog-theme']`，没有则跟随 `prefers-color-scheme`，**在首次绘制前**设好，避免闪白
- 所有颜色通过 CSS 变量切换，不维护两套样式表
- 代码块用 Shiki 双主题：浅色内联 `github-light`，深色走 `--shiki-dark` 变量

## 六、三条硬约束

1. **不写死颜色**：新增样式必须用变量；确需新色，先加到 `:root` 两个块里
2. **不改类名**：`.post-item` / `.tag` / `.hero` 等已被模板引用，改名会静默丢样式
3. **改配色必须重算对比度**：正文与链接不得低于 4.5:1
