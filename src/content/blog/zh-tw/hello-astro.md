搭這個部落格，最直接的原因是：筆記散在太多地方了。

微信收藏、備忘錄、Obsidian、各種 Markdown 檔案，還有一堆沒整理的聊天記錄。
需要查的時候找不到，找到的時候又過期了。

所以想有個自己的地方，能長期維護、能被搜尋、能訂閱。

## 為什麼選 Astro

選型時主要看三條：**靜態、零維護、寫作體驗好**。

- 靜態網站：沒有資料庫、沒有後端，部署就是傳檔案，十年後也能跑。
- 零維護：不裝外掛、不升級依賴也不會掛。
- 寫作體驗：一篇 Markdown 就是一個檔案，Git 管版本。

Astro 預設不往瀏覽器塞 JavaScript，頁面就是純 HTML + CSS，
首屏快，而且不用擔心框架版本升級帶來的破壞性變更。

## 一個最小的頁面長這樣

```astro
---
const title = '你好，世界';
---
<h1>{title}</h1>
```

沒有客戶端框架，沒有 hydration，建置完就是一坨靜態檔案。
