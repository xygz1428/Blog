When reading papers or textbooks, the most common illusion is "I understand."
When I close the book, I find that I can't speak. This is because I don't have enough depth of understanding, not because of my memory.

I currently use a very crude method, let’s call it the **Three Times Method**.

## The first pass: only draw the structure

Without copying the content, just answer one question: **What is this section demonstrating? **

- Copy the title into a tree shape and mark the role of each level (definition/lemma/experiment/discussion).
- Write the conclusion of each paragraph in one sentence, without any derivation.
- When you encounter a term you don’t understand, just put a question mark without digging deeper.

The output this time is a structural diagram, which can be completed within ten minutes.

## Second pass: only write the derivation

It was the second time that I got serious about it, but it only focused on the areas marked with question marks in the first time.

The key is: **Handwriting, don’t read the original text**. Where you get stuck are your true blind spots.

- If you can figure it out, write down the key steps in one sentence.
- If you can't push it out, check it back and then use a red pen to make up for it.
- After completing the supplement, close the original text and push it again.

## The third pass: only output

The third time without looking at the notes, try to explain it to someone else.

- Can’t tell → Go back to the second time.
- It can be said but it is verbose → It means that the core has not been grasped yet.
- Can explain clearly in three sentences → Basically pass the test.

## a little experience

| Common practice | question |
|---|---|
| copywriting notes | The hands are moving, but the brain is not moving |
| Just draw mind maps | The structure is there, but the derivation is missing. |
| Collect a bunch of information | Collect and forget |

The core of the three-pass method is not "three", but **clear outputs for each pass**:
Structural diagrams, derivation fragments, verbal explanations. A pass without output does not count.
